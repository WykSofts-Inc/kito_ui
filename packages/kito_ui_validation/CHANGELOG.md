## 0.1.0

- First release: `KitoValidationRule` with 23 built-in rules plus `strongPassword()` and `&` / `|` / `optional` / `when` composition, `kitoValidate`, `kitoValidateAll`, `kitoEvaluate`, `formValidator` for `TextFormField`, `KitoPasswordScore` with suggestions, `KitoAsyncValidationRule` / `KitoAsyncValidator` (debounced, stale-safe), `KitoFormFieldController`, `KitoFormController`, `KitoFormScope`, `KitoValidationTrigger`, and digit normalisation for Arabic, Persian and other scripts.
